# Hummingbirds World

https://hummingbirds.world

An interactive explorer of all 363 hummingbird species (family Trochilidae): browse them by family tree, world map, size and conservation status, with photos and a 3D anatomy page.

A static site: serve this folder over HTTP and open `index.html`. The species and country pages (English and Spanish) and `sitemap.xml` are generated by the scripts in `scripts/`; run `sh scripts/build_all.sh` (Python 3.12+ and Node) after changing data, `index.html` or the scripts. Data sources and credits are in the site's "About & credits" dialog.
