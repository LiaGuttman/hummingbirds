# Hummingbirds World

https://hummingbirds.world

An interactive explorer of all 363 hummingbird species (family Trochilidae): browse them by family tree, world map, size and conservation status, with photos and a 3D anatomy page.

A static site with no build step. Serve this folder over HTTP and open `index.html`. Data sources and credits are in the site's "About & credits" dialog.
